# Metrics Definition Summary

Purpose: provide one shared definition reference for both qualitative and quantitative metrics used in this project.

Scope note:

- Current quantitative implementation is program-only (coaching, learning communities, resources, city engagement).
- Current qualitative implementation uses the Q1-Q10 coding framework.

## 1) Quantitative Metrics Definition

Quantitative metrics are numeric indicators that measure how much, how often, or how efficiently a program activity is occurring over time.

In this project, quantitative metrics are:

- Program-output focused
- Computed from structured fields (counts, rates, percentages)
- Reported on monthly, quarterly, and annual cadence
- Scored with a weighted annual model (0-4 per metric, rolled up to 100)

Current quantitative metric set (program-only):

- P1 Authentic Relationship Development (Non-Linear Signal Set)
- P2 Coaching Conversations
- P3 Coaching Level Progression Rate
- P4 Active Learning Communities
- P5 Learning Community Participation
- P6 Resource Production Velocity
- P7 Resource-to-Engagement Conversion
- P8 City Engagement Touchpoints
- P9 Relationship Continuity (30-day)

Primary reference:

- [docs/governance/program-annual-evaluation-2026.md](docs/governance/program-annual-evaluation-2026.md)

## 2) Qualitative Metrics Definition

Qualitative metrics are evidence-coded indicators that measure the quality, depth, and pattern of mission practice through narrative data.

In this project, qualitative metrics are:

- Meaning-and-behavior focused
- Derived from coded evidence excerpts (stories, coaching notes, transcripts, journals)
- Scored on a 0-3 rubric (Not observed to Strong, transferable pattern)
- Reviewed monthly with quarterly synthesis and contradiction checks

Current qualitative metric set:

- Q1 Listening-First Posture
- Q2 Discernment Responsiveness
- Q3 Grace-Centered Gospel Framing
- Q4 Relational Continuity Depth
- Q5 Kingdom-Sign Recognition
- Q6 Service-Shaped Leadership
- Q7 Community Belonging Formation
- Q8 Faith-Language Personalization
- Q9 Resilient Dependence Under Pressure
- Q10 Contextual Witness Fit

## 3) Key Differences

Quantitative metrics:

- Answer: How much happened?
- Data form: counts and rates
- Typical output: trend lines, percentages, weighted annual score
- Main risk: measuring activity volume without quality context

Qualitative metrics:

- Answer: What kind of formation and witness is happening?
- Data form: coded narrative evidence
- Typical output: rubric scores, pattern narratives, exemplar evidence
- Main risk: interpretation drift without coding discipline

## 4) How They Work Together

Use both layers in the same review cycle:

- Quantitative layer verifies delivery volume and progression.
- Qualitative layer verifies posture, integrity, and formation quality.

Annual decision rule:

- No major program conclusion should be made from one layer alone.
- Positive annual judgment requires both:
  - Quantitative attainment at or above planned threshold
  - Qualitative evidence showing non-contradictory, consistent practice

## 5) Shared Governance Rules

- Theological non-contradiction applies to all interpretation.
- Evidence and calculations must be traceable to source artifacts.
- Any metric definition change should be versioned in governance docs before use.

This matrix pairs the current quantitative and qualitative measures by program pillar.

| Program Pillar | Quantitative Metrics | Qualitative Metrics | Primary Annual Question |
| --- | --- | --- | --- |
| Coaching | P1 Authentic Relationship Development; P2 Coaching Conversations; P3 Coaching Level Progression | Q1 Listening-First Posture; Q2 Discernment Responsiveness; Q8 Faith-Language Personalization | Are relationships developing authentically, and is coaching forming people in Christ-centered practice? |

- First read quantitative movement (volume, participation, progression).

- Final judgment requires both layers to point in the same direction.
