# Qualitative Metrics Framework v1

Purpose: define a practical, repeatable qualitative metrics system for Proxima that is aligned to theological convictions, activity units, faith markers, and values.

Authority baseline:
- [docs/governance/theological-convictions.md](docs/governance/theological-convictions.md)
- [docs/governance/tangible-activities-from-convictions.md](docs/governance/tangible-activities-from-convictions.md)
- [docs/governance/critical-faith-markers.md](docs/governance/critical-faith-markers.md)
- [docs/governance/sharepoint-story-intake-and-mapping.md](docs/governance/sharepoint-story-intake-and-mapping.md)
- [data/source/values-proxima-partners.md](data/source/values-proxima-partners.md)

Non-contradiction rule:
- Any qualitative metric interpretation that contradicts the authority baseline must be revised or rejected.

## 1) Metric Design Standard

Every qualitative metric must include:
- Metric ID and name
- Why it matters
- Evidence source types
- Coding rule (what counts)
- 4-level rubric (0-3)
- Activity/marker/value anchors
- Review cadence
- Owner

Rubric scale for v1:
- 0 = Not observed
- 1 = Emerging signal
- 2 = Consistent signal
- 3 = Strong, transferable pattern

## 2) Evidence Source Types

Primary source types for coding:
- Coaching notes and session summaries
- Zoom/ViewSpark/meeting transcripts
- Email narratives and updates
- Webflow stories and article content
- Journal excerpts and reflection notes

Minimum evidence quality standard:
- Include source ID, date, actor/context, observed behavior, and short excerpt.

## 4) Coding Workflow

1. Select evidence batch (monthly).
2. Assign source IDs and extract short excerpts.
3. Code each source against Q1-Q10 (0-3 each).
4. Record anchors (A, M/J, values) for every coded metric row.
5. Flag contradictions against theological baseline.
6. Review in monthly qualitative metrics meeting.
7. Publish score and narrative summary quarterly.

## 6) Governance Rules

- Minimum row completeness: source_id + excerpt + metric_id + score + anchors.
- Contradiction override: if contradiction_flag = Y, row cannot be counted toward positive trend.
- Dual-review rule: quarterly sample of at least 20% rows coded by a second reviewer for consistency.
