## Scoring Rubric (Uniform Evaluation)

Use this rubric for every extracted activity from journals, Proxima Pete, and CMS stories.

### Scale A: Alignment Strength (0-2)

- 0 = Misaligned
- The activity directly contradicts one or more convictions.

- 1 = Partial / unclear alignment
- The activity is directionally consistent but missing clear theological clarity or has mixed signals.

- 2 = Strong alignment
- The activity clearly and positively demonstrates the mapped convictions with no contradiction.

### Scale B: Evidence Quality (0-2)

- 0 = Weak evidence
- Vague or implied activity with no concrete behavior described.

- 1 = Moderate evidence
- Some observable behavior present, but details are incomplete (who/where/how/result).

- 2 = Strong evidence
- Concrete behavior is documented with context and outcome signals suitable for coding/measurement.

### Scale C: Replicability (0-2)

- 0 = Non-replicable
- One-off event with no transferable practice.

- 1 = Limited replicability
- Can be repeated in some settings, but process is not yet clear.

- 2 = High replicability
- Clear pattern or practice that can be repeated and trained across contexts.

### Weighted Score

Compute:

`total_score = (2 x Alignment Strength) + (1 x Evidence Quality) + (1 x Replicability)`

Maximum score = 8

### Decision Thresholds

- 0-3 = Reject or revise
- Do not use as exemplar activity until conflict/clarity is resolved.

- 4-5 = Provisional
- Keep with notes; needs clarification or stronger evidence.

- 6-8 = Approved exemplar
- Include in activity library and metric development pipeline.

### Contradiction Rule (Override)

If Alignment Strength = 0, the activity is automatically disqualified regardless of other scores.
